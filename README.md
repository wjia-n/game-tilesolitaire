# Tile Solitaire

A calm zen-garden tile-matching game by Wajiha. Clear all 144 bamboo tiles
from the raked sand by matching pairs of free tiles.

- 3 hand-built 144-tile layouts (Turtle, Pagoda, Bridge)
- Free-tile rules: uncovered + open on at least one side
- Flower & season tiles are wild (match any honor tile)
- Scoring with chain bonuses, hints, shuffle rescues, undo
- Procedurally synthesized calm audio: bamboo taps, soft chimes, garden ambience
- Settings with music/SFX toggles and volume sliders (persisted)
- In-progress game saved automatically; continue any time

Package: `com.gameswajiha.tilesolitaire`

## Getting Started

```sh
flutter pub get
flutter analyze
flutter run
```
